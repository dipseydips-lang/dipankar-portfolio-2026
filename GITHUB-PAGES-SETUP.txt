GITHUB PAGES SETUP

1. Create/sign into GitHub.
2. Create a PUBLIC repository named:
   YOUR-GITHUB-USERNAME.github.io
3. Upload every file in this folder to the ROOT of that repository.
   Do not upload the containing folder itself.
4. Open Settings > Pages.
5. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save.
7. Wait for GitHub Pages to publish the site.
8. Your live URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/

IMPORTANT:
- Keep index.html in the repository root.
- The .nojekyll file is already included.
- Replace YOUR-GITHUB-USERNAME with your actual GitHub username in robots.txt and sitemap.xml before publishing.
